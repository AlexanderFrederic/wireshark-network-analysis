Wireshark Network Analysis

A network traffic analysis project using Wireshark to examine common networking protocols, packet behavior, and troubleshooting concepts.

This repository began as coursework for Computer and Communication Networks at Rutgers University and is being developed into an ongoing networking portfolio project.

2025 Coursework

The original project involved capturing and analyzing network traffic using Wireshark. I completed four protocol focused labs covering DNS, DHCP, ICMP, and IP.

DNS

Analyzed DNS queries and responses, UDP port 53 traffic, resource records, name servers, and DNS caching behavior.

DHCP

Examined DHCP communication including client discovery, broadcast and unicast behavior, UDP ports 67 and 68, transaction IDs, address assignment, and network configuration.

ICMP

Used Wireshark, ping, and traceroute to analyze Echo Request and Echo Reply traffic, ICMP header fields, TTL behavior, network hops, and changes in round trip time.

IP

Analyzed IPv4 and IPv6 packet headers, TTL values, protocol identifiers, changing header fields, packet fragmentation, and IPv6 addressing information.

2026 Independent Analysis

I plan to revisit and expand this project through independent packet captures and additional network analysis.

Future work will focus on applying Wireshark to practical troubleshooting scenarios and exploring network behavior beyond the original coursework.
